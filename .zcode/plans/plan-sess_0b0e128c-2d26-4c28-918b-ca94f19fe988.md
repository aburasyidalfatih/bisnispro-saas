# Rencana Audit Mendalam — SchoolPro

Project: Next.js 15 (App Router) + React 19 + TypeScript strict + Prisma/PostgreSQL (RLS) + NextAuth v5, SaaS multi-tenant untuk sekolah. Skala besar: 300+ API route, ~40 fitur, schema 2500+ baris.

## Deliverable
Satu file **`AUDIT.md`** di root — laporan terstruktur berisi: temuan per-kategori, severity (Critical/High/Medium/Low), lokasi `file:line`, dampak, dan rekomendasi perbaikan. **Tidak ada perubahan kode** pada tahap ini.

## 8 Sisi yang Akan Diaudit

### 1. Keamanan & Otorisasi (PRIORITAS)
- Cross-tenant IDOR: route yang percaya `tenantId` dari client tanpa cek membership (temuan awal: `api/finance/cashflow` bisa baca/tulis lintas-sekolah; ~48 route sekelas).
- Konsistensi guard: duplikasi `lib/tenant-guard.ts` vs `lib/guards/tenant-guard.ts`; hanya 44 route pakai `requireTenant*`.
- Pemakaian `withTenant()`/RLS vs akses `db` langsung.
- Validasi input di boundary (Zod hanya ~74 file), rate limiting, secrets, CSP/headers.

### 2. Arsitektur & Struktur
- Separation of concerns: business logic + Prisma inline di `route.ts`/`page.tsx` (service layer di-bypass di 238 route).
- God components (30-65KB): `attendance/gtk/overview`, `gtk/presence`, dll.
- Konsistensi pola antar fitur.

### 3. Type Safety & Kualitas Kode
- ~996 `: any` + ~372 `as any` — meski strict mode aktif.
- `typescript.ignoreBuildErrors: true` & `eslint.ignoreDuringBuilds: true` di next.config.
- Error handling: ~393 `catch(e:any)` yang membocorkan `error.message` ke client, tidak konsisten dgn logger/Sentry.

### 4. Database & Prisma
- Pola N+1, unbounded `findMany`, index, penggunaan raw SQL (aman/parameterized?), migrasi & RLS.

### 5. Performa
- Caching, connection pool, edge/middleware (512 baris), verifikasi klaim commit optimasi terakhir.

### 6. Testing
- Cakupan (17 test file untuk project sebesar ini), area kritis tanpa test (auth, finance, tenant isolation).

### 7. DevOps & Config
- CI/CD (deploy workflow disabled, cron aktif), Docker/nginx/traefik, env validation (manual, bukan Zod), Dockerfile, backup scripts.

### 8. Kebersihan Repo & Dependency
- File sampah di root (`query*.sql`, `test-*.ts`, `scratch.js`, `rclone.zip` 29MB, `update.tar`), banyak dir config AI agent duplikatif, audit dependency (versi, deprecated, `next-auth beta`).

## Cara Kerja
Menggunakan beberapa Explore agent paralel untuk sweep tiap kategori, membaca file kunci secara langsung untuk verifikasi temuan, lalu menulis `AUDIT.md` dengan temuan berbukti (bukan asumsi) beserta severity dan rekomendasi konkret.

Setelah laporan selesai, saya bisa lanjut memperbaiki isu Critical (mis. IDOR finance) jika Anda setujui.
